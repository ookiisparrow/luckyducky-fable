# 决策日志模板（append-only）

> 规则: 只追加, 不修改历史条目。每条一个 commit, 可 diff 可回滚。
> 未经验证的结论 = 参考假设, 禁止作权威依据。

## 决策条目

- 时间: YYYY-MM-DDTHH:MM:SS
- 操作者: (main/reviewer-B/verifier-C/human)
- 输入快照 hash: (git commit 或 sha256)
- 结论: (一句话)
- 依据: (工具输出引用 / 代码位置 / 测试结果)
- 适用条件:
- 失效条件:
- 置信度: (high/medium/low; 未校准前仅作排序)
- 来源: (自身判断 / B票 / C票 / 人工)
- 验证状态: (已验证[测试|lint|人工|线上] / 待验证 / 已失效)
- 覆盖/推翻原因: (谁覆盖了谁, 为什么; 无则填 "-")

---

## 示例

- 时间: 2026-08-10T23:50:00
- 操作者: main
- 输入快照 hash: 23693e8
- 结论: 交叉验证协议采用"盲审→反驳→证据裁决→仍争议才人工"
- 依据: docs/多模型流水线v2方案.md §3; codex 复核 2026-08-10
- 适用条件: 所有 L0 任务
- 失效条件: 协议修订且双票通过时
- 置信度: high
- 来源: 人工决策(分歧后)
- 验证状态: 已验证[人工]
- 覆盖/推翻原因: -

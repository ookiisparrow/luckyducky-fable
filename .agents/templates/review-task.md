# 交叉验证审查任务模板（发给 B/C）

> 每次 L0 任务复用。发送前把 <占位> 替换为实际内容。
> 要求: 独立审查, 互不可见, 结构化输出, 带证据。

## 任务文本（发给 B/C 的 prompt 骨架）

```
请对以下变更做独立审查（挑错者角色, 不要附和）。

输入快照: <git commit hash 或文件路径>
变更上下文: <见 .agents/contexts/LD-xxx.md>

审查要求:
1. 独立审查, 不参考其他审查者意见
2. 重点找: 逻辑错误/安全漏洞/边界情况/与既有约定冲突
3. 每条意见必须结构化: {类型, 位置(文件:行), 复现步骤, 证据, 影响, 置信度}
4. 无意见也要明确说"通过"
5. 输出格式: 按严重程度排序(严重/中等/轻微) + 通过结论

请用中文回答。
```

## 归档规则
- B/C 原始输出 → .agents/archives/<LD编号>-<票名>-<时间>.md（不可变, 同批 commit）
- 主控不得改写/删减/合并后再存
- 争议清单由归档原始输出生成

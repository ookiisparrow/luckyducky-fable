# 001 激活码：备货封码、不绑订单、验收扫码裁决

## 决定
唯一激活码在备货阶段封入包装，只属 `(courseId, batchId)`，**不与订单/订单条目绑定**；退货权最终以**验收扫码**裁决（已激活拒退，未激活可退），`confirmEnter` 启发式失效仅作展示性标记。

## 背景
备货时码已封入盒内，发货拣货无法也无需知道盒内码号，「发货时绑订单」物理上不成立。退货权若只靠订单字段，送礼场景会失真；须回到随包装走的物理凭证。

## 备选
1. 发货时扫码绑订单条目  
2. 内外双码（外箱码绑单、内码激活）  
3. 备货封码 + 不绑单 + 验收扫码兜底（现案）

## 为何不选
1. 封装盒无法在发货环节打开查码。  
2. 多物料、多一道扫码，被否。  

## 后果
- `qrcodes` 无 `orderId`/`orderItemRef`；发货零绑码动作。  
- `refundable` 不可当最终裁决；验收 SOP 必须「寄回完整包装 + 必扫码」。  
- 改绑单模型或取消验收扫码前，须先改本记录。

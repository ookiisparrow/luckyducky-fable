# 002 印刷码：普通链接二维码 `/q/<码>`

## 决定
印刷物料用**普通链接二维码**（形如 `https://<域名>/q/<激活码>`），交付「码→网址」清单给印刷厂；**不用**小程序码（`wxacode.getUnlimited`）也**不用**永久 URL Link。

## 背景
印刷要活数年、流程要最简，且客服/验收需肉眼可读码尾段。小程序码要逐码出图占接口；永久 URL Link 微信已不支持。

## 备选
1. 小程序码 + scene  
2. URL Link（永久）  
3. 普通链接二维码一码一地址（现案）

## 为何不选
1. 要生成图文件、占接口配额，尾段不可肉眼读。  
2. 微信不支持永久有效链接，印刷年限不匹配。  

## 后果
- 依赖 ICP 备案域名 + 小程序后台「扫普通链接二维码打开小程序」规则 + 真机验。  
- `genQrcodes` 只产码；导出拼网址前缀；welcome 兼容 `?q=` / `?code=` / scene。  
- 改回小程序码或换路径约定前，须先改本记录。

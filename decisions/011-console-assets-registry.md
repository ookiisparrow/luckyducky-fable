# 011 控制台资产正册（git 外真相）

## 决定
系统真实形态 = **git 内代码 + git 外控制台配置**。支付/退款连接器与工作流、库权限、复合索引、VOD、云函数现网规格、downloadFile 域名等**正册化**于 `console-assets/`（密钥 REDACTED）；**变更纪律：先改正册副本，再动控制台**。

## 背景
这些资产不在 git，误删即支付/退款/播放瘫痪（根因#9）；代码与 CLI 往往读不到安全规则。无正册则重建靠猜。

## 备选
1. 只靠控制台现场点选、不入仓  
2. 正册副本 + drift-checklist + 先 repo 后控制台（现案）  
3. 试图用代码完全替代控制台工作流

## 为何不选
1. 无版本、无重建手册、易漂。  
3. 微信支付连接器等工作流目前锁在云开发；切换成本另案。  

## 后果
- 关键 ID 以正册为准（例：连接器 `wxpay_33nb7su`、主支付流 `sywxzfapifqzf_nncvqss2`、退款流 `kbgzl_n8gojr3a`、VOD 任务流 `LuckyDuckyVod` 等——细节见各分册）。  
- 上线前/迁移后跑 README drift-checklist。  
- 废弃正册纪律或改接缝 ID 而不改正册，视为违纪。

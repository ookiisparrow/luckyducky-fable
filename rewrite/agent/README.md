# rewrite/agent · 坐席台走查手册

> **为什么靠人**（根因#8）：轮询合并、认领互斥都有测试钉着，但「接待顺不顺手、消息会不会闪重」只有真用验得了。**坐席台是在用人工客服唯一通道**：线上 `/agent` 跑的就是本包构建产物，改动先本机演练走查、验过再部署（部署纪律见 `docs/运维手册.md` §1.3·人工授权动作）。
>
> **本机启动**：`cd rewrite/agent && npm run dev`（端口 5174）→ 坐席口令登录（或企微内带 ?code= 免登）。

## 接待全流程演练（需要两个身份配合：你的手机扮顾客 + 浏览器扮坐席）

| # | 步骤 | 看什么 | 结果 |
|---|---|---|---|
| 1 | 顾客在小程序找客服发一句话 | 坐席台 10 秒内队列出现该会话、显示「等了 X 秒」 | |
| 2 | 点「接」 | 会话进「我在接」、聊天窗打开、能看到顾客点转人工**之前**说的话（10 分钟回溯） | |
| 3 | 回复顾客 | 顾客微信里收到；**坐席输入框只在发送成功后清空**；长回复接近 2000 字上限时显示字数 | |
| 4 | 顾客再发消息 | 3 秒内出现在聊天窗、**不出现重复气泡** | |
| 5 | 看右侧 360 | 顾客同意过数据共享→显示画像/订单；没同意→如实提示「按规定不能看」 | |
| 6 | 第二个坐席账号同时点「接」同一单 | 后到者被拒「已被别人接走」 | |
| 7 | 放回队列 / 升级给商户 | 会话回队列可再接；升级件在**超管**队列里标黄可重接 | |
| 8 | 结束会话 | 顾客收到满意度评分气泡（点星 1–5 或直接回数字 1-5 都算）；顾客回 3 → 满意度报表 +1 条 | |
| 9 | 切状态 在线→忙碌→离线 | 不报错（推送分配随状态·后台行为） | |
| 10 | 关掉标签页再开 | 「我在接」还在（刷新不丢现场） | |
| 11 | 顾客发一张图片 | 聊天窗出现图片气泡、点开能看大图；图片过期/加载失败有提示可重试，不白屏 | |
| 12 | 用快捷回复 | 点 chip 文案插进输入框（知识库拉不到时快捷回复整行隐藏、不报错） | |
| 13 | 切去别的标签页时顾客来新消息 | 标签页标题出角标 + 提醒短音；切回来角标清零；关掉提醒开关后不再响不再改标题 | |

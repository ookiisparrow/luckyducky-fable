# 主流程存档 v0.0.2（含 bot 情绪表演）

定稿演练版。本仓落地以老板拍板 mermaid + 选句 1→4 为准。

## 情绪两层（不可混）
1. **顾客情绪状态**：Jev 判断输入（激动/着急/不满/困惑/犹豫/平稳…）
2. **bot 情绪表演**：话术输出（安抚/同理/道歉/犹豫/澄清/平稳专业/轻松收尾/惊讶尴尬）  
   顾客激动 ≠ 客服激动；仅确认我方失职才道歉表演。

## 主线路上的表演节点
1. 判完顾客情绪后 → **选演法**
2. 责任归属后 → **表演复核**（尤其道歉）
3. 承诺尽力解决前 → **承诺语气表演**
4. 请求配合时 → **请求语气表演**
5. 给出解决办法时 → **给办法语气表演**

## 主流程摘要
进线 → Jev打招呼/提需求 → 订单售前/售中/售后 → 问题树  
→ Jev顾客情绪 → **bot情绪表演** → 严重程度 → 责任归属 → **表演复核**  
→ 信息充分？复述或追问 → **承诺前表演** → 承诺尽力解决  
→ 配合/核实？→ **配合/给办法表演** → 解决办法；配合循环最多3次转真人

穿插：停顿、思考、犹豫、惊讶/尴尬、要图、禁气泡等仍有效。

## 选句优先级（本仓，勿反）
1. 订单 orderStatus
2. 情绪 emotionStatus
3. 严重程度 severity
4. 责任 responsibility
需求仍识别（超出预期→犹豫；要图→拍照），不抢前四步。

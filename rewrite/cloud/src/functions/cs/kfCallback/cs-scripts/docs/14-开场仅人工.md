# 「人工」呼唤

## 规则
- **第 1 次**：用「怎么了？😳」池，不转接
- **第 2 次**：用「您直接说吧」池，不转接
- **第 3 次**：不回复，直接转接

同会话两池内不重复已用过的短句。

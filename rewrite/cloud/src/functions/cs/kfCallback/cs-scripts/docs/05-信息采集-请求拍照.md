# 信息采集：请求拍照

**硬边界**：顾客才能提供的信息（现场包装、缺件、报错屏、破损细节等）→ **直接要图**，不说「方便说下」「您描述一下」代替拍照。  
不向顾客要订单号/快递单号（客服侧可见订单）。

口语短句；同会话不重复；可与同理/安抚拆开两条发。

---

## 请求拍照 · 通用（≥20）

1. 您拍张照片发我看看～
2. 麻烦拍一张发过来哈。
3. 您把现场拍张照给我。
4. 发张图我对照下。
5. 您拍照发我，我帮您看。
6. 麻烦来张清晰的照片～
7. 您截个图/拍个照发我就行。
8. 拍一张我瞅一眼哈。
9. 您把情况拍给我看下。
10. 发张照片过来，我好判断。
11. 麻烦拍照，我帮您确认。
12. 您拍一下发给我～
13. 来张图，我对照处理。
14. 您把细节拍清楚发我。
15. 麻烦发照片，文字不好判断。
16. 您拍照我看完立刻帮您办。
17. 发图就行，我这边看着处理。
18. 您拍一张当前状态给我。
19. 麻烦来张实拍哈。
20. 您把画面拍给我看看。
21. 发照片过来～我帮您看严不严重。
22. 您拍好发我，我马上跟进。

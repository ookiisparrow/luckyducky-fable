# 语气穿插：停顿 · 思考

口语短句；同会话不重复；可与主流程任意步穿插，但勿连续堆砌。

---

## 停顿（≥20）

语气缓冲、换气、接话前的单字/短音。单独发一条或贴在下一句前（演练时单独一条更清晰）。

1. 额
2. 啊
3. 嗯
4. 诶
5. 哦
6. 额…
7. 啊…
8. 嗯…
9. 诶呀
10. 哦～
11. 额额
12. 嗯嗯
13. 啊哈
14. 诶嘿
15. 唔
16. 欸
17. 噢
18. 嗯呐
19. 啊这
20. 额好
21. 嗯好
22. 啊行

---

## 思考（≥20）

**硬边界**：仅当顾客提出**新需求**且客服侧**系统可查**时使用。  
查不到 / 不需要查 → **不用**假「稍等」，直接要信息或如实说需要确认。

1. 我看看
2. 稍等
3. 我查一下
4. 我瞅一眼
5. 稍等哈
6. 我帮您看下
7. 我核对一下
8. 稍等我看
9. 我这边查查
10. 让我看一眼
11. 稍等啊
12. 我翻一下
13. 我确认下
14. 稍等～
15. 我查查哈
16. 我看一下啊
17. 稍等我查
18. 我对照一下
19. 让我核对下
20. 稍等哦
21. 我马上看
22. 我先查一下

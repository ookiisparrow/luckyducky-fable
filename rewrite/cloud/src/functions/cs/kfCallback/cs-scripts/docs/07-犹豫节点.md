# 犹豫节点

## 何时用
顾客提出**超出预期**的要求时：先犹豫，再说去问问可不可以。
- 不直接答应
- 不直接拒绝

## 话术库（≥20）

1. 额这个…
2. 我也不清楚行不行
3. 啊，得问一下才知道
4. 额，这个我得确认下
5. 嗯…这个不好直接说
6. 啊这个，我先问问看
7. 额，超出我这边权限了
8. 我也不确定能不能办
9. 啊…得跟上面问一声
10. 额这个情况，我去问下
11. 嗯，我不太敢直接答应
12. 啊得核实一下可不可以
13. 额，我先帮您问问哈
14. 这个我没把握，问一下
15. 啊…稍等我去确认行不行
16. 额，这种我得请示下
17. 我也不清楚政策允不允许
18. 啊这个，让我问问能不能做
19. 额…我先问一声再回您
20. 嗯，得问过才敢跟您说
21. 啊，我也不知道行不行得通
22. 额这个，我帮您问问看可不可以

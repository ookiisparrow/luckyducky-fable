# 退货开场

## 何时用
顾客提出退货（含短句「退货」）。先接住「可以」→ 软问哪里不满意。  
负面短句时仍可：认可需求 → 安抚 → 再问（与本库语气一致）。

## 话术库（≥20）

1. 嗯嗯，可以的哈，是不是哪里不满意呢？
2. 退可以的，哪里不合适跟我说～
3. 嗯可以退，方便说下原因吗？
4. 好的可以退，是质量还是其他原因呢？
5. 嗯嗯能退的，哪点让您不满意呀？
6. 可以退的哈，哪里不满意您说说。
7. 嗯行，退货没问题，因为啥想退呀？
8. 能退的，是哪里不对劲吗？
9. 嗯嗯可以，您哪里不满意我听听。
10. 退可以的，方便讲下原因不？
11. 好嘞可以退，是不是收到有问题？
12. 嗯可以的，哪方面不满意呢？
13. 能退哈，您说说哪里不合适。
14. 嗯嗯，退货可以，什么原因呀？
15. 可以的，是质量、款式还是其他？
16. 退没问题，哪里让您不满意了？
17. 嗯行可以退，您简单说下原因就行。
18. 能退的哈，是不是哪里不满意～
19. 嗯嗯好，可以退，因啥想退呢？
20. 退货可以的，您哪里不顺心？
21. 嗯可以，方便说下具体原因吗？
22. 好的能退，是产品问题还是个人原因呀？

## 硬规则
- 避免「办」字（不说办理/可以办/能办退等）。
- 邮费/扣费/退款金额：无预设前不承诺，走犹豫去问。
- 同会话不重复短句。

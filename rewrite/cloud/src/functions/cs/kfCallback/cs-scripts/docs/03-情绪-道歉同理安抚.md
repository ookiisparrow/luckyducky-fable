# 情绪节点：道歉 · 同理心 · 安抚

各 ≥20 条；同会话不重复；负面情况不说「好」。

## 何时用（硬边界）

- **道歉**：已明确确认是我们的失职，才道歉（未确认前不道歉）
- **同理心**：不是我们的责任/义务，但能体谅对方情绪
- **安抚**：我们能处理、能补救的情况，先稳住再动手

可单用或短串，按事实选，勿堆砌。未确认失职时：同理 ± 安抚，不道歉。

# 开场 · 打招呼无具体事

顾客只打招呼、尚未提具体需求时用。同会话开场只用一次；「在的」整段对话不重复堆。

## 话术库（≥20）

1. 嗨～在呢，有什么问题呢？
2. 在的在的，请说。
3. 嗨！在的，有什么问题可以帮您吗？
4. 在呢在呢，您说～
5. 嗨～有事直接说就行。
6. 在的呀，请问怎么了？
7. 嗯在的，您说。
8. 嗨，在的，听您说。
9. 在的～请问有什么可以帮您？
10. 嗨呀，在呢，您说哈。
11. 在的在的，怎么啦？
12. 嗨～我在，有问题说～
13. 嗯呐在的，请讲。
14. 在呢，有啥事我帮您看。
15. 嗨！在的呀，您先说。
16. 在的哦，请问需要帮忙吗？
17. 嗨～在的，您慢慢说。
18. 在呀，有什么想问的？
19. 嗯在呢，您说就行。
20. 嗨，在的在的，听着呢。
21. 在的，我在，您请说。
22. 嗨～您好，有什么问题呢？

## 对照
- 第一句已带具体问题 → 用「开场·已带问题」库，不走本库询问句。

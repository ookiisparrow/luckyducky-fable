# 专题：收到后 · 课程/程序进不去

挂在主流程第 5–6 步。口语短句；同会话不重复。

## 责任口径（硬）

- **未确认失职前：不道歉**
- 路径：**同理 → 安抚 → 要截图**（直接要图/截图）
- 定性后再决定是否道歉、是否走技术升级

---

## 同理（进课场景）

1. 啊理解，进不去是挺急。
2. 理解，卡在门口换谁都烦。
3. 知道您着急用课。
4. 嗯理解，打不开确实闹心。
5. 体会，想学却进不去挺火大。

## 安抚

1. 别着急哈，这个我们能帮您看。
2. 没事，我来帮您排查。
3. 放心，常见能处理好。
4. 别慌，我一步步跟您弄。
5. 不着急，我对完状态就告诉您。

## 要截图

1. 您把进不去的报错截图发我～
2. 卡在哪一屏就截哪一屏发过来。
3. 完整报错页截一张，我帮您排。
4. 您把提示字那屏截图发我。
5. 激活/登录失败的画面拍给我看下。

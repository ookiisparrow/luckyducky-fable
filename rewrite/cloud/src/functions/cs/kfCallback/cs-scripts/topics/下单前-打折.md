# 专题：下单前 · 打折 / 优惠

挂在主流程第 5–6 步。口语短句；同会话不重复。

## 硬边界

- **不确定政策不编造**：有无券、能否改价、活动是否叠加，以可查活动/后台为准。
- 查不到 → 如实说要确认，不用假「稍等」假装有折扣。
- 不向顾客要订单号（尚未下单则无；已有意向单客服侧查）。

---

## 复述

1. 您是想问能不能优惠一点对吧？
2. 我确认下，是问有没有折扣或券哈？
3. 也就是想看下单前有没有满减？

## 查后有优惠

1. 目前有【活动名/券】，满【门槛】减【金额】。
2. 这款可叠【券说明】，下单页能勾。
3. 现在活动价就是【价】，已含优惠。

## 查后无优惠 / 需确认

1. 我查了下，这款暂时没有额外折扣。
2. 现价就是展示价，没有暗折。
3. 活动规则我要再确认一下，确认后回您。
4. 不确定能否改价，我先问清楚再答复，不跟您瞎说。

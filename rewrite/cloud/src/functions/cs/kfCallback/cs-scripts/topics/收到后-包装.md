# 专题：收到后 · 包装破损

挂在主流程第 5–6 步。口语短句；同会话不重复。

## 责任口径

- **外包装破损责任在物流公司**（非默认我方仓内失职）。
- 未确认产品损坏前：**不道歉认领失职**；可用同理 + 体验向歉意表述。
- 产品确有损坏 → **安抚** + 帮联系物流 / 按售后政策补救（不确定政策不编造）。

---

## 要合照

1. 您拍一张包装和产品放一起的合照发我～
2. 外箱破口和产品都入镜拍一张发过来。
3. 包装+内物合照一张，我帮您看产品有没有事。
4. 麻烦拍清晰点，破损位置也要入镜。
5. 您把箱子和产品放一块拍给我。

## 产品没事 · 体验歉意+同理

1. 产品本身没问题，包装成这样体验不好，理解。
2. 货是好的，箱子磕成这样确实糟心。
3. 里面没事就好，包装破损换谁都烦。
4. 产品OK，外包装这份体验确实差，理解您。
5. 确认产品没伤着；包装这样是挺郁闷的。

## 产品有事 · 安抚+跟进

1. 别着急，产品这事我们帮您跟。
2. 没事，我帮您联系物流一起处理。
3. 放心，损坏这块我们按流程给您补救。
4. 别慌，我先帮您登记跟进。
5. 我们能处理，您先把图留着我这边推进。

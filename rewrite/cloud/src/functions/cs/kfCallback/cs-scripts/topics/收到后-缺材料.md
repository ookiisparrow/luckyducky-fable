# 专题：收到后 · 缺材料

挂在主流程第 5–6 步。口语短句；同会话不重复。  
不向顾客要订单号（客服可见订单与地址）。

---

## 要图确认

1. 您把打开的包装拍一张，我帮您对清单。
2. 缺的部位和现有材料一起入镜发我。
3. 盒子内部（含夹层）拍一张给我看看。
4. 您把已有的材料摊开放一起拍张照发我。
5. 发张开箱图，我对照该有哪些件。

## 提醒再找

1. 您再翻一下夹层，有的会塞在缝里。
2. 袋底和说明书袋也看一眼哈。
3. 泡沫缝、纸板夹层常见会漏看。
4. 您再对一下清单，有时小件贴在底板。
5. 内袋拉链层再掏一下～
6. 外箱角落纸垫下面也看看。
7. 配件袋可能粘在说明书背面。
8. 您再找一轮，找不到我们立刻补。

## 仍找不到 · 立刻补发+确认地址

1. 没事，我们给您补发。
2. 别着急，缺的这块我们补寄。
3. 找不到就补，我这边马上办。
4. 我核对下订单地址是【地址】，对吗？
5. 收件信息我按订单上的【地址】，没改过吧？
6. 地址确认后我提交补发。
7. 补发提交好了跟您同步。
8. 您不用报单号，我这边看着订单处理。

# 专题：发货前 · 加急 / 催发

挂在主流程第 5–6 步。口语短句；同会话不重复。  
不向顾客要订单号（客服可见订单与发货状态）。

## 硬边界

- **不确定政策不编造**：能否插队、几点前截单、是否已拣货，以系统状态为准。
- 可查 → 思考 → 如实报状态与能否加急。
- 不可查 / 无加急通道 → 不假承诺「一定今天发」。

---

## 同理+表态

1. 理解，着急用。
2. 知道急，我帮您看能不能提前。
3. 嗯理解，我查下排期。
4. 换我也想快点拿到。
5. 我先看这单到哪一步了。

## 查后可加急

1. 还在待发，我帮您备注加急了。
2. 截单前还能赶，已帮您标优先。
3. 拣货中，我催一下仓库侧。

## 查后不可加急 / 需如实

1. 这单已过今日截单，最早【日期】发。
2. 当前加急排满了，按正常【时效】。
3. 状态是已发，转查物流就行。
4. 能不能再提前我确认下，确认后回您。

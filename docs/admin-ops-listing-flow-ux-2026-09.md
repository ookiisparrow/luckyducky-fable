## 先说结论（可直接转述）

店员要上一个新套装，**能走通**，但默认路径不是一条龙：

1. 点「新建商品」会在商品表**下面**弹出一张大表，**不会**自动进入「上新向导」。
2. 表里能填名称、卖点、价格、展示销量、封面和相册；**没有库存格子**。新规格没建库存档＝顾客能一直买（不限量）。库存页也**没有**「给新规格建档」按钮。
3. 填完显示「已自动保存」，顾客还看不见。要再点「上架」。改价、改展示销量也一样。
4. 第一次上架会**自动进首页人气条**。想只在目录里卖、不上首页，还得再去「小程序橱窗」关开关。
5. 教学视频、激活卡、印刷码是后三步，**不是上架硬门槛**；但入口拆在三个菜单、两套名字。

后台**没有**优惠券 / 发券入口（没有把测试券搅进正式后台）。批次页「测试二维码」是印刷前用手机扫一下验落地页，不是券。

钱相关：没发现「一点就按错价卖、后台还拦不住」的洞。上架有封面/名称/价格/规格四道门。已下架再点「恢复销售」**不会**把刚改的草稿同步出去——这是容易踩的同步坑，不是乱改价。

## 1. 完整流程地图

假设店员刚拿到口令，要上「初学者钩织学习套装」。按时间顺序。

## 2. 卡点 / 绕路 / 命名混乱

每条：步骤号、现象、为什么伤运营、严重度。与 #195 重复的标 **「已有」**。

### L1 · 步 3–4、8b · 页头说「一条流水线」，新建却不进向导（新）

- **现象**：页头写「产品图片 → 商品信息 → SKU → …」。右上「＋ 新建商品」只在本页下方打开编辑器。六步向导藏在进度小圆点或「⋯ → 上新向导」。
- **为什么伤**：新店员按页头走，会以为自己已经在流水线上；其实后三步（课 / 卡 / 码）完全没进。老人也要多点一次「⋯」。
- **严重度**：P1

### L2 · 步 5、14 · 上新表没有库存；新规格默认不限量（新）

- **现象**：商品表单没有「库存」格。库存页只显示已有档；空页还写「不限量无档是正常的」。没有「给这个新规格建档」的按钮。
- **为什么伤**：店员以为「没填库存就不会卖」或「上架时会一起设库存」。实际是：没建档＝顾客能一直下单。想限量，还得绕去进销存组装，或等以后有人补建档入口。
- **严重度**：P1（认路 + 卖超预期；不是改价漏洞。服务端有库存档才会限量）

### L3 · 步 5 · 「销量」看起来像库存或真实卖出（新，部分 **已有**）

- **现象**：「销量」和价格排在同一排。占位「0 不在详情页显示」。#195 已写：这是手填展示数，不是订单加总。
- **本次补一句**：它还容易被当成「库存」。库存在另一个菜单组，名字叫「实物库存」。
- **为什么伤**：填错数，顾客看到假「已售」；或以为填了销量就是限量。
- **严重度**：P1（文案；**已有** 骨架 + 本次补「和库存撞车」）

### L4 · 步 6 · 商品价和规格价要填两遍（新）

- **现象**：头上「价格（元）」是上架大门之一；规格行还要再填「价格（元）」。列表价取规格最低价，多规格旁标「起」。
- **为什么伤**：只填头上的价、忘了加规格，上架按不了。只填规格、头上留空，也过不了门。两个数不一致时，顾客看到的是规格价。
- **严重度**：P1（认路，不是算错钱的后门——下单按库里规格价）

### L5 · 步 8、10、16 · 「上架 / 恢复销售 / 重新上架 / 更新上架信息 / 上架橱窗」（**已有** + 向导确认句）

- **现象**：#195 第 3 条已写三套商品上架词。本次补：向导在售时按钮是「更新上架信息」，点下去仍问「确认上架？」；橱窗开关又叫「上架橱窗」。
- **为什么伤**：改完价想「让顾客看到新价」，不知道点哪颗。
- **严重度**：P1 **已有**

### L6 · 步 16 · 已下架商品改完价，列表只有「恢复销售」，不同步草稿（新）

- **现象**：已下架一行主按钮是「恢复销售」——只把旧上架页重新露出来，**不拷刚改的草稿**。列表「⋯」里的「重新上架」（才会拷草稿）**只在「在售」时出现**。已下架想同步新价，只能钻进向导点「更新上架信息」，再点「恢复销售」。
- **为什么伤**：店员下架改价再恢复，顾客仍看到旧价/旧图，以为改好了。
- **严重度**：P1（同步坑；服务端故意不让「恢复」顺便改价，防悄悄复活，但界面没把「先同步、再恢复」说清）

### L7 · 步 10、15 · 第一次上架会自动进首页人气条（新）

- **现象**：第一次上架，云端默认打开「首页推荐」。商品列表徽章变「在售」后，店员不一定知道首页已经挂上。要关掉得到「小程序橱窗」。
- **为什么伤**：试卖、还不想打首页广告的款，会直接出现在首页。
- **严重度**：P1

### L8 · 步 11 · 商品上架和课程发布是两套按钮（新）

- **现象**：商品「上架小程序」≠ 课程「发布上线」。课还可以先「已自动存草稿」（学员看不见）。视频传完若还在转码，要再点「同步转码状态」才能发布。
- **为什么伤**：顾客买到套装，扫码进课，可能还是空课或旧课。向导第 4 步进度圆点只问「有没有视频文件」，不问「课发布了没有」。
- **严重度**：P1

### L9 · 步 4、9 · 向导前三步同一张大表；第 6 步「完成」回商品列表（**已有**）

- **严重度**：P2 **已有**（#195 第 12 条）

### L10 · 步 12–13 · 一张激活卡，三个名字、两个菜单组（**已有**）

- **现象**：卡片设计 / 二维码卡片 / 激活码批次 / 二维码批次 / 码批次与印刷包。设置页还写着设计器「待补齐」（已经有了）。
- **严重度**：P1 **已有**（#195 第 4 条）

### L11 · 步 2、13 · 关联课程、批次都要认 `course-xxx`（**已有** + 上新链）

- **现象**：商品格占位 `course-xxx（可空）`；批次页空态「输入课程编号（course-xxx）」；课程页同样。向导里系统会自己用 `course-商品编号`。
- **为什么伤**：从侧栏进批次/课程，不像从向导进来那样带着编号，店员要抄一串内部号。
- **严重度**：P2 **已有**（#195 第 14 条）

### L12 · 步 6 · 材料清单图标是英文单词（新）

- **现象**：下拉是 `circle`、`pen-tool`、`package`，不是「毛线团 / 针 / 包装」。
- **为什么伤**：店员不知道选哪个，顾客详情页图标可能乱。
- **严重度**：P2

### L13 · 步 5 · 封面/相册会压到很小，界面没说（新）

- **现象**：上传后前端压到约 720 像素宽、体积很小。超了只说「换小一点的图」，不说「顾客端图会变糊」。
- **为什么伤**：用精修大图的人以为原图进了小程序。
- **严重度**：P2（体验，不是卖错价）

### L14 · 步 8b、9 · 向导左侧一步、顶上一排，名字还不完全一样（**已有**审美 + 本次点名）

- **现象**：侧栏「视频上传 / 码批次与印刷包」，顶栏「教学视频 / 码批次」。
- **严重度**：P2 **已有**（#195 文末）

### L15 · 步 2 · 看板「上新未完成」只数「还没上过架的」，不管六步做没做完（新）

- **现象**：已在售但没传课、没出码的，看板当 0。点瓦片只到商品列表，不进向导未完成步。
- **为什么伤**：老板以为「上新都做完了」，其实印刷卡还没出。
- **严重度**：P2

## 3. 易用性优化建议

按「改名 / 并入口 / 减少一步 / 文案」排，不谈大翻修。钱相关只动说法和入口，不改计价规则。

| 优先 | 改什么 | 对应卡点 | 店员会怎样更好 |
|---|---|---|---|
| 改名 | 「商品管理」和页标题统一成「商品」；「上架 / 重新上架 / 更新上架信息」在售时改成「同步到小程序」；橱窗开关改成「出现在首页」 | L5 **已有** | 改完价知道点哪 |
| 改名 | 向导确认句跟按钮走：更新时问「顾客将看到新价格/新图？」不要再问「确认上架？」 | L5 | 少吓一跳 |
| 改名 | 「销量」改成「详情页展示的已售件数（可填 0 表示不显示）」 | L3 **已有** | 不再当库存 |

## 4. 理想的一条龙上架路径（运营视角 · 7 步）

目标：店员不用理解草稿/发布两张表、不用抄课程编号。

1. **登录 → 上新**（看板或侧栏一个「上新」入口，直接开向导）。
2. **填商品**：名称、卖点、封面/相册、价格（一个规格自动带上）、展示已售（可选）。顶上写清「还没给顾客看」。
3. **（可选）限量**：就在这张表填「可卖件数」；不填＝不限量，并用人话说出来。
4. **（可选）配套课**：上传视频并「发布给已买的学员」；没有课也可以先卖材料包。
5. **（可选）激活卡**：画卡 → 定稿 → 出一批码 → 下载印刷包（网址前缀没配时，就在这一屏提示去填，不要让人找「系统」）。
6. **上架给顾客买**：一颗主按钮「上架到小程序」；成功后问一句「要不要同时出现在首页」。
7. **以后改价 / 改展示已售**：仍在商品页改，旁边一颗「让顾客看到这次修改」——不要再叫「重新上架」。

这 7 步覆盖「能卖 + 能限量 + 能出码 + 能改价同步」。课程和印刷卡保持可选，不挡先卖。

# 运营与增长规划

> 运营 / 增长 / 营销 / 生态战略**单源**（2026-06-15 立）。这里只放「怎么想 / 方向」；可执行项落地时入册 `docs/待办与债.md`（走 `/refactor-batch`），产品功能需求归 `docs/需求清单.md`，技术决策归 `docs/关键决策记录.md`；状态单源、不在此漂移。

## 时机三层（总纲）

运营动作按成本与时机分三层：**① 上线前必埋钩子**（能力 / 数据结构 / 入口 / 来源埋点——后补极贵）· **② 上线初期 0→1**（私域沉淀 + 召回）· **③ 增长期 1→N**（内容 SEO/GEO + 裂变活动）。

## 一、SEO / GEO

**核心认知**：微信小程序内容不在公网，传统 Web SEO 不适用。三战场：
- **微信搜一搜（主战场）**：小程序名 / 服务类目 / 关键词定对 + 搜一搜内容收录——微信内免费精准流量。
- **公网 SEO**：用 H5 端做可索引的内容 / 落地页站，承接百度 + 公众号外链，引流回小程序（核心交易仍走小程序，T1 不破）。
- **GEO（让生成式 AI 推荐）**：抓手在站外权威语料——小红书 / 知乎 / B站教程、公众号长文。
- **时机**：名称 / 类目 / 关键词＝① 上线前定（改名有成本）；内容站 / GEO＝③ 增长期（依赖真实内容，非上线阻塞）。
- 落地状态查 `docs/关键决策记录.md` §29（mp 分发放开 + 内容站扩面）；后台人工项台账见 `docs/人工配置清单.md`。

## 二、营销策略（开发期埋钩子）

后补极贵的，开发期就埋（数据结构 / 能力 / 入口 / 埋点）：
- **分享裂变**：`onShareAppMessage` + 分享卡片 + 带参路径追来源（已落地：`docs/需求清单.md` R29 · 决策§29）。
- **来源埋点**：`trackEvent` 记 scene / 渠道——营销 ROI 地基（漏斗埋点已落地：`docs/需求清单.md` R41）。
- **订阅消息**：提前申模板（订单 / 发货 / 上新 / 开课）+ 埋授权入口——低成本召回。
- **优惠券 / 促销**：数据结构预留（`docs/需求清单.md` R20 占位）。
- **拼团 / 砍价 / 新人券**：依赖分享 + 订单来源，结构预留。
- **小程序码带参**：海报 / 印刷扫码追渠道。
- **时机**：埋点 / 能力 / 结构＝① 上线前；活动运营＝上线后。**最贵的三样**：分享能力 + 来源埋点 + 订阅消息模板。

## 三、其余方向（只留线索）

- **运营 bug 收集**：用户反馈入口 + 前端错误上报；端侧监控走小程序后台官方三件套（`docs/运维手册.md` §⑤·台账 `docs/人工配置清单.md`），bug 闭环记 `docs/调试日志.md`。
